# stakehq.xyz — site is intentionally kept out of search results and
# AI training corpora for now.
#
# Two different mechanisms are used on purpose:
#
#   1. Search engines (Google, Bing, etc.) are ALLOWED to crawl. Every page
#      serves <meta name="robots" content="noindex, ..."> and a crawler can
#      only obey noindex if it is permitted to fetch the page and read it.
#      Blocking them here instead would leave already-indexed URLs stuck in
#      the index as bare, snippet-less results.
#
#   2. AI training / scraping crawlers are DISALLOWED outright. They do not
#      populate a search index, so there is nothing to de-list, and a full
#      block is the strongest signal available.
#
# No sitemap is published, by design.
